## 0. 結論（先に）

1. **CMC 専用の独立オラクルとして使える厳密な事実が 3 つある**。どれも Jacobian の式を使わずに
   導ける。
   - **(I) 回転不変量の定理**：等方的なエネルギー（E = 0 を含む）なら、拘束アンサンブル
     M̂ = n における回転不変量の分布は、拘束しない iid（または等方 Boltzmann）の分布に一致する。
     N = 2, 3 では ⟨M_z⟩, ⟨M_z²⟩, P(e_i·n < 0) が閉じた式になる
     （4/3, 2；13/8, 3, 1/8）。
   - **(II) 回転 iid 参照サンプラ**：iid 一様スピンを最小回転で M̂ → n に回したものは、E = 0 の
     拘束アンサンブルの**厳密なサンプル**になる。それを e^{−βE} で重み付けし直せば、
     任意のハミルトニアン・任意の小さな N で ⟨A⟩_n と F(n) の不偏推定量になる。
     N = 2 ならこれが 2 次元の決定論的求積になる。
   - **(III) 単イオン線形応答の恒等式**：K → 0 で K_eff(T) = K·⟨P_l(e_i·M̂)⟩_iso(T) が、
     有限の N でもすべての T で厳密に成り立つ。右辺は**既存の `run_mc`**（等方モデル）で測れる。
     Callen–Callen 則の「厳密版」なので、漸近則の代わりのゲートになる。
2. **ガードの盲点（試作で確認）**：ordered 相・大きい N では、M_z² の Jacobian の誤りがほぼ
   見えない（N = 32, T = T_c/2 で τ のずれ 1.3 %）。一方 |z_j| 因子の誤りは示量的に見える
   （12 %）。Jacobian のゲートは**小さい N か E ≈ 0 で張る必要がある**。
   「等方モデルでトルク 0」は一点ごとに成り立つ恒等式（Noether）なので、アンサンブルについて
   何も検査しない。
3. **設計への要望**（テストできるようにするため）。
   (a) pair 提案を「(新状態, log 受理比)」を返す内部関数として切り出す。G4 で使う。
   (b) 非活性サイトの規約と拘束が衝突する。モーメントを持つ非活性サイトは拘束を通じて結合する
   ので、凍結すると分布が偏る。CMC では動かすか、M から外すかを決めて仕様に書く。
   (c) pair 更新は色クラスの中でも可換でない（M_z² と |z_j| を通じて大域的に結合する）。
   並列化は θ 点・温度・独立チェーンの間に限る。

## 1. 規約と導出（オラクルの前提）

### 1.1 拘束アンサンブル

モーメント m_i（重みなしなら全部 1）、M = Σ_i m_i e_i、拘束方向
n(θ, φ) = (sinθ cosφ, sinθ sinφ, cosθ)。拘束アンサンブルは M̂ の周辺分布を条件付けた
ものとして定義する：

  μ_n(de) = e^{−βE(e)} δ_{S²}(M̂ − n) Π_i dΩ_i,  P(n) = ∫ μ_n,  F(n) = −kT ln P(n).

n = ẑ の近くで δ_{S²}(M̂ − ẑ) = M² δ(M_x) δ(M_y) θ(M_z) であり、拘束面上では M = M_z なので

  μ_ẑ = e^{−βE} M_z² δ²(M_⊥) θ(M_z) Π dΩ_i.   … (1)

pair (i, j) の更新は、ほかのスピンを固定したファイバー上の動き。e_j を (x_j, y_j) で表すと
dΩ_j = dx_j dy_j / |z_j| なので、δ² を e_j で積分すると、e_i を座標とするファイバー密度は

  ρ_{ij}(e_i) = e^{−βE} M_z² / (m_j² |z_j|),  z_j の符号は保つ    … (2)

e_i の提案が dΩ_i に関して対称なら、受理比は
r = e^{−βΔE} (M_z'/M_z)² |z_j| / |z_j'|（m_j² は打ち消す）。これが Asselin の式。
棄却条件は M_z' ≤ 0（θ(M_z) から）と x_j'² + y_j'² > 1。
**逆移動で元に戻るには z_j の符号を保つことが必要**で、これは G4 の可逆性検査の対象になる。

### 1.2 トルク恒等式（有限 N で厳密）

e → R e の大域回転について、測度は不変で、M̂ は同変（M̂(Re) = R M̂(e)）。だから
F(R_u(α) n) = −kT ln ∫ e^{−βE(R_u(α) e)} μ⁰_n。α で微分すると

  dF/dα = ⟨Σ_i ∇_i E · (u × e_i)⟩_n = −⟨u · T⟩_n,  T = Σ_i e_i × (−∇_i E).   … (3)

ここで u は θ を増やす回転軸 u = (−sinφ, cosφ, 0)。v = n × u は
⟨v·T⟩ = −(1/sinθ) ∂F/∂φ の向きの軸で、n 自身については

  ⟨n · T⟩_n = 0 （どのハミルトニアンでも厳密）.   … (4)

（n のまわりの回転は拘束も測度も保つから。）(3) と (4) は熱力学極限を使っていない。
モーメントの重みはトルクに入らない。重み付きの M でも T は重みなしの和。

### 1.3 オラクル (I)：回転不変量の定理

E が回転不変（E = 0、または等方 Heisenberg）なら、e^{−βE} Π dΩ は回転不変。だから
μ_n = R_* μ_ẑ（R ẑ = n）となり、回転不変な観測量 f の μ_n 平均は n によらない。
∫ dΩ_n μ_n = e^{−βE} Π dΩ であることと合わせると、
**⟨f⟩_{CMC,n} = ⟨f⟩_{拘束なし}**。Jacobian の式は一切使っていない。

- **N = 2, E = 0**：M = e₁ + e₂ ∥ n ⇔ e₂ = 2c n − e₁、c = e₁·n > 0。
  cosγ = e₁·e₂ = 2c² − 1 は iid で [−1, 1] 一様なので、c² が [0, 1] で一様。
  ⇒ c の密度は 2c。⟨M_z⟩ = 2⟨c⟩ = **4/3**、⟨M_z²⟩ = **2**、P(e_i·n < 0) = 0。
  （ρ ∝ M_z²/|z_j| = 4c²/c ∝ c と一致する。式 (2) の独立な検算になっている。）
- **N = 3, E = 0**：r = |e₂ + e₃| の密度は r/2（[0, 2]）、u = e₁·r̂ は一様。
  R = |M| の密度は p₃(R) = R²/2（0 ≤ R ≤ 1）、R(3 − R)/4（1 ≤ R ≤ 3）。
  ⟨M_z⟩ = ⟨R⟩ = **13/8**、⟨M_z²⟩ = **3**（一般に Σ m_i²）、
  P(e₁·M̂ < 0) = P(1 + r u < 0) = ∫₁² (r/2)(1 − 1/r)/2 dr = **1/8**。
- **等方結合つき**（パッケージ内では E = 0 だと全サイトが非活性になるので、実際にはこちら）。
  N = 3 の環（`_chain_terms`、dims = (3,1,1)）では E = J(R² − 3)/2 になるので、上の式を
  e^{−βE(R)} で重み付けした 1〜2 次元の求積が厳密な参照になる。
  P(e_i·n < 0) は (r, u) の 2 次元求積。N = 2 では e₁·e₂ = 2c² − 1 なので、密度は
  2c·e^{−βJ'(2c²−1)} の 1 次元求積。J は `_dimer_J` と同じやり方で、エネルギー差から読む。
- **重み付き N = 2**、m = (1, 2)：R_w² = 5 + 4u、⟨R_w⟩ = **13/6**、⟨R_w²⟩ = **5**。

### 1.4 オラクル (II)：回転 iid 参照（任意のハミルトニアン、小さい N）

e が iid 一様のとき、n₀ = M̂(e) に対して、R(n₀) n₀ = n を満たす任意の可測な回転
（たとえば最小回転）を作用させると、R(n₀)_* μ⁰_{n₀} = μ⁰_n になる
（μ⁰_ẑ は ẑ まわりの回転で不変）。だから e' = R(M̂(e)) e は E = 0 の拘束アンサンブルの
厳密なサンプル。これを重み付けし直すと

  P(n)/P₀ = E_iid[e^{−βE(e')}],  ⟨A⟩_n = E_iid[A(e') e^{−βE(e')}] / E_iid[e^{−βE(e')}].

E には `total_energy`（全エネルギーをゼロから計算する経路。`test_energy.jl` でオラクルとして
確立済み）か、手書きの閉じた式を使う。重み付き版は M̂_w で同じことをする。
有効域：重みの分散が小さいところ（N ≲ 4〜6、β|E| ≲ 数）。N ≳ 10 の ordered 相では
ESS ~ e^{−Var(βE)} で破綻する。
**N = 2 は決定論的な求積に落ちる**：

  P(n) = ∫_{e₁·n > 0} dΩ₁ 4(e₁·n) exp[−βE(e₁, 2(e₁·n) n − e₁)].   … (5)

(c, φ₁) の Gauss–Legendre × 台形則で滑らかに収束する（64 × 128 点で 1e−10 程度。
格子を倍にして自己収束を assert する）。トルクは F の中心差分か、(3) を求積で直接評価して出す。

### 1.5 オラクル (III)：単イオン線形応答の恒等式（Callen–Callen の厳密版）

E = E_iso + E_K、E_K = −K Σ_i (e_i·ẑ)² = −K Σ_i [⅔ P₂(e_i·ẑ) + ⅓] とする。
μ⁰_n（等方）は n まわりの回転で不変なので、単一サイトの法則は n まわりに軸対称。
加法定理を方位で平均すると ⟨P_l(e_i·ẑ)⟩ = P_l(n·ẑ) ⟨P_l(e_i·n)⟩_iso。だから

  F(θ) = F_iso + ⟨E_K⟩_{iso,n} + O(βK² N)
       = const − N K ⟨P₂(e·M̂)⟩_iso cos²θ + O(βK²N)
  F(θ) ≡ const − N K_eff cos²θ と定義すると
  K_eff(T) = K ⟨P₂(e·M̂)⟩_iso(T)·[1 + O(βK)],  ⟨u·T⟩ = −N K_eff sin 2θ.   … (6)

l = 4（立方 K₁）なら ⟨P₄(e·M̂)⟩_iso。右辺の ⟨P_l(e·M̂)⟩_iso は回転不変量なので、定理 (I) により
**拘束しない `run_mc`（等方モデル、既存で検証済み）で測ってよい**。CMC のコードは一切通らない。

- N = 2, E_iso = 0：⟨P₂(c)⟩ = ∫ 2c P₂(c) dc = **1/4** ⇒ K_eff = K/4。
- 低温では ⟨P_l⟩ ≈ 1 − l(l+1)/4 ⟨δ²⟩、m ≈ 1 − ⟨δ²⟩/2 なので
  ⟨P_l⟩ ≈ m^{l(l+1)/2}。これが Callen–Callen 則で、(6) の帰結。
- K を小さくしても相対精度は落ちない（信号もゆらぎも ∝ K）。だから βK = 1e−3 などとして
  O(βK) の補正を 0.1 % に抑えられる。

## 2. ゲート一覧（各ゲート：保証 / オラクル / フィクスチャ / 潰すミューテーション / 許容幅 / 所要時間）

共通フィクスチャ（すべて `fixtures.jl` の流儀に合わせて手書きの `MultipoleTerm` で作る）：

- **F2**：`TiledHamiltonian(2, terms)`、dims = (1,1,1)。2 原子、等方 l = 1 ペア（folded は単位行列。
  `_chain_terms` の書き方）＋ 各原子に body-1 l = 2 単イオン項。
  - F2u：folded は m = 0 だけ。z 軸の一軸異方性。
  - F2g：folded は m = −2..2 に乱数。二軸で F が φ にも依存する。
  - J と K はエネルギー差から読み取る（式を推測しない）。
  - 重み付き版は `magmoms = [1.0, 2.0]`。field を入れると Zeeman 項がつくので、M の重みとしてだけ
    使う API が必要。これは設計で決めること。
- **F3**：3 原子、3 本の等方ペア（全対）＋ 3 体の手書き項 ls = [1,1,1]、folded[2,2,2] = 1
  （∝ λ e₁ᶻe₂ᶻe₃ᶻ。異方的で、**時間反転について奇**）＋ 単イオン l = 2。
- **F4**：4 原子、4 体 folded[2,2,2,2]（`_fourbody_terms` と同じ型）。
- **F3ring**：`TiledHamiltonian(1, _chain_terms(J); dims = (3,1,1))`。E = J(R² − 3)/2、全サイト活性。
- **FL**：sc 4×4×4 の等方 Heisenberg（`_chain_terms` を 3 方向に広げたもの、または
  `_stacked_chain_model` 系）＋ 微小な単イオン K。

拘束方向は、特に断らない限り**一般の n**（θ = 0.6, φ = 0.35）。θ = 0 だと lab 系と n 系が
一致するので、lab 系で補償するバグが見えなくなる。

### Tier A：決定論的・ユニットスイート（各 ≪ 1 s）

**G1 拘束の不変量（受理のたびに、繰り込みと再射影の後にも）**
- 保証：受理された pair 移動の後と `_renormalize!` の後のたびに、
  |M_⊥| ≤ tol、M·n > 0、‖e_i‖ = 1、sign(z_j) が保存される。
  繰り込み（各スピンの正規化）は M_⊥ を丸め誤差だけ動かすので、**再射影**
  （n への微小な大域回転、またはスピン 1 本での補正）が必要。そのあとエネルギーをゼロから
  再アンカーする。
- オラクル：テスト側でゼロから計算した M_⊥ = M − (M·n)n（増分で追跡している M は使わない）。
- フィクスチャ：F2g と、重み付きの 8〜27 サイト格子（m が不等）。一般の n。
  10⁴ 回の移動ごとに検査する。
- 許容幅：移動ごとの丸めはランダムウォークなので、10⁴ 回の移動後の
  |M_⊥| ≤ 1e−12·Σm_i、再射影の直後は ≤ 1e−14·Σm_i（数 ulp）。
  初回の実測値を記録し、そこから余裕を持たせる。
- 潰すもの：
  - lab 系での補償（n ≠ ẑ のとき O(1) のずれ）。
  - 重みなしの補償シフト × 重み付きの拘束（重み付き/重みなしの取り違え）。
  - j = i の許容：M_⊥ ← M_⊥ + e_i⊥ − e_i'⊥ となり、ずれる。j ≠ i の assert も別に置く。
  - 再射影の欠落（ずれが単調に増える）。
  - z_j の符号を常に + にする。
  - 繰り込み後のエネルギー再アンカーの欠落（既存の drift ゲートとも重なる）。

**G2 pair ΔE の厳密性（全エネルギー差と比較）**
- 保証：pair 移動の ΔE が total_energy(after) − total_energy(before) と 1e−12 で一致する
  （test_energy の慣行どおり worst < 1e−13）。i と j が同じインスタンスに入っていても成り立つ。
  正しい増分は ΔE = c_i·ΔZ_i、zrows[i] を更新、c_j（更新後の i で計算）·ΔZ_j。
- オラクル：`total_energy`（ゼロから計算する経路）。F2 のように手書きで閉じた式がある場合は、
  それとも比べる。
- フィクスチャと対：
  (a) 同じ 2 体インスタンス（F2）。
  (b) 同じ 3 体インスタンス（`_threebody_terms`、dims = (4,1,1)）。
  (c) 同じ 4 体インスタンス（`_fourbody_terms`、dims = (5,1,1)）。端どうし (1,4) を含む。
  (d) 複数のインスタンスを共有する対（2 体 + 3 体の混合）。
  (e) 共有しない対。
  **テスト内で `H.inst_ptr/inst_sites` を使って、(a)〜(d) が実際に共有していることを assert
  する**（共有していなければゲートは空振りになる）。
- 追加で、棄却後のロールバックについて：zrows == `_zrows(H, config)` がビット単位で一致し、
  st.energy が不変であること。
- 潰すもの：
  - 旧配置に対する ΔE_i + ΔE_j（交差項 ~ |J| ~ 1e−2 ≫ 1e−12）。
  - 先に zrows[j] を更新してしまう、などの順序ミス。
  - 棄却時の zrows[i] の巻き戻し漏れ。
  - 補償後の e_j の Z 行を作り忘れる。

**G3 トルク観測量の一点ごとの恒等式**
- 保証：各配置について、T·w = −d/dα E(R_w(α) e)|₀ が w ∈ {u, v, n} で成り立つ。
  加えて、等方モデルでは T ≡ 0 が一点ごとに成り立つ。
- オラクル：`total_energy` を大域回転して中心差分（h = 1e−5、相対 1e−7）。
  勾配のコード（`energy_gradient!`）を使わない。
- フィクスチャ：F2g、F3（3 体）、FL の小片。一般の (θ, φ)。
- 潰すもの：
  - トルクの符号。
  - 軸の取り違え（u ↔ v、n）。
  - u(φ) の符号規約。
  - 2 倍などの因子。
  - 勾配の接線成分の取り方。
  - Zeeman 項の寄与の漏れ。
- 残るもの：アンサンブルの誤りはすべて残る（これは観測量の検査）。

**G4 受理比の詳細釣り合い恒等式（サンプリングなし、厳密）**
- 保証：実装の log 受理比 ℓ(x→y) が、テスト側で式 (2) から独立に書いた
  log ρ_ind(y) − log ρ_ind(x) = −βΔE + 2 ln(M_z'/M_z) − ln|z_j'| + ln|z_j|
  と丸め誤差で一致する。ΔE はテスト側で `total_energy` の差として計算する。
  加えて：
  - 提案写像の可逆性：y から e_i を戻す提案をすると x に戻る（‖·‖ ≤ 1e−14）。
  - ℓ(x→y) = −ℓ(y→x)。
  - 不正な状態（M_z' ≤ 0、x² + y² > 1）では ℓ = −∞。
- 前提：設計要望 (a)。内部関数 `_cmc_pair_proposal(st, H, i, j, e_i′) -> (y, ℓ)` のような形。
- 独立性：ρ_ind の式は G5 で（Jacobian によらない定理 (I) から）検証される。
  G4 は「コードがその式をすべての分岐で実装しているか」を担当する。
- フィクスチャ：F2g、F3、重み付き F2。ランダムな状態・対・提案を 10³ 組。
- 潰すもの：
  - Jacobian の欠落、M_z の指数 2→1、|z| 比の反転、|z| 因子の欠落。
  - 重み付き/重みなしの M_z の取り違え。
  - G2 が通っていても ℓ の中の ΔE を符号を誤って使う、など。
  - z 符号の分岐を + 固定にする（可逆性で失敗）。
  - M_z' ≤ 0 の棄却漏れ。
  - β の二重適用。

### Tier B：統計・ユニットスイート（各 ~0.5〜3 s）

**G5 幾何ゲート（E = 0／等方、N = 2, 3）：Jacobian の主ゲート**
- 保証：CMC の定常分布の回転不変な周辺分布が、定理 (I) の閉じた式に一致する。
- オラクル：§1.3。⟨M_z⟩, ⟨M_z²⟩, P(e_i·n < 0)。パッケージでは F3ring と 2 サイト等方を使い、
  e^{−βE(R)} で重み付けした 1〜2 次元の求積と比べる。βJ = ±0.5 程度。
  重み付き版は m = (1, 2) で 13/6, 5 を使う（E = 0 の場合。結合があれば求積）。
- 試作で確認したミューテーション感度（E = 0、numpy、2000 チェーン × 1500 ステップ）：

| 変異 | N=2 ⟨M_z⟩ | N=2 ⟨M_z²⟩ | N=3 ⟨M_z⟩ | N=3 ⟨M_z²⟩ |
|---|---|---|---|---|
| 厳密値 | 4/3 = 1.3333 | 2 | 13/8 = 1.625 | 3 |
| 正しい実装 | 1.3333 | 1.9999 | 1.6259 | 3.0023 |
| Jacobian 欠落 | 0.571 | 0.762 | 1.007 | 1.473 |
| M_z 指数 2→1 | 1.000 | 1.334 | 1.333 | 2.166 |
| \|z\| 比の反転 | 1.600 | 2.667 | 1.774 | 3.646 |
| \|z\| 因子の欠落 | 1.500 | 2.400 | 1.764 | 3.532 |
| 指数 1 かつ \|z\| 欠落 | **1.334（N=2 では見えない）** | 2.0015 | **1.447** | 2.564 |

  N = 2 では M_z = 2c、|z_j| = c なので M_z^a/|z_j|^b ∝ c^{a−b} となり、a − b が同じ変異は
  区別できない。**だから N = 3 が必須**。
  さらに z_j の符号を + に固定するバグは N = 2 では見えない（N = 2 では常に z_j = c > 0）。
  N = 3 の P(e·n < 0) = 1/8 で捕まる。M_z' ≤ 0 の棄却漏れは ⟨M_z⟩（M_z² ではない）で捕まる。
- 許容幅：
  - N = 2 では Var(M_z) = 2 − 16/9 = 0.222。有効サンプル 2×10⁴ で SE ≈ 0.0033、
    atol = 5σ ≈ 0.017。最小の変異シフト（|z| 欠落）は 0.17 で、10 × atol。
  - N = 3 では Var = 3 − (13/8)² = 0.36。atol ≈ 0.02。最小の変異シフトは 0.14〜0.18。
  - パッケージの binning 誤差 `err` を使い、test_zeeman と同じ書式でコメントに残す
    （seed、測った err、偏差、atol = kσ、分解すべき変異の大きさ）。
    `err < ε_max` も assert して空振りを防ぐ。
- 時間：N ≤ 3 で pair 移動 ~10⁶ 回。< 1 s の見込み。
- 残るもの：ΔE の誤り（E が R だけの関数で、ペアが全対なら naive な ΔE の誤差は
  ⟨M⟩ に偏って現れるが、G6/G2 に任せる）、トルク関連はすべて。

**G6 N = 2 異方二量体のトルク vs 決定論的求積（パイプライン全体の主ゲート）**
- 保証：⟨u·T⟩_n = −∂F/∂θ、⟨v·T⟩_n = −(1/sinθ)∂F/∂φ、⟨n·T⟩_n = 0（式 (3), (4)）。
  F は (5) の求積から計算する。
- フィクスチャ：F2u（θ ∈ {0.3, 0.6, 1.2}）、F2g（一般の (θ, φ)。φ 依存をつくる）、
  重み付き F2g（m = (1, 2)）。J < 0 で、βJ ~ 1〜2、βK ~ 0.5〜1。
- 試作（J = −1, K = 0.5, β = 2, θ = π/5）：
  - 求積 −dF/dθ = −0.66686。
  - 回転 iid の参照 −0.66701。
  - CMC −0.66708。
  - Jacobian 欠落 −0.5537（17 % のずれ）。
- 潰すもの：
  - Jacobian 系すべて（N = 2 なので有限 N の効果が大きい）。
  - 二量体では i と j が必ずインスタンスを共有するので、naive な pair ΔE（交差項 J Δe_i·Δe_j）。
  - トルクの符号・軸、θ の規約の逆転（F2u でトルクの符号が反転する）、φ の規約（F2g）。
  - トルクに m_i を掛ける誤り（重み付き F2g）。
  - 補償の座標系。
- 許容幅：求積誤差は格子倍化で < 1e−10 を assert。CMC 側は binning σ の 5 倍。
  Jacobian 変異のシフト（0.11）が ≥ 5 × atol になるようにサンプル数を決める。
- 時間：求積は 8192 回の評価で ~10 ms。CMC は ~10⁶ 移動 × 3 点で ~1〜2 s。

**G7 N = 2 線形応答の恒等式（小 K）**
- 保証：(6) を N = 2 で確認する。E_iso = 0 なら K_eff = K/4、等方 J があれば
  K_eff = K⟨P₂(c)⟩_J（c の密度 ∝ c·e^{−βJ'(2c²−1)} の 1 次元求積）。
- 価値：G6 と重なるが、オラクルがさらに単純で、トルクの規格化（N・sin2θ の因子）を独立に固定できる。
  Jacobian 欠落なら c が一様になり ⟨P₂⟩ = 0 → K_eff = 0 なので、強く殺す。
- 時間：< 1 s。G6 に入れられなければここで代わりにする。

### Tier C：遅い／手動検証（`bench/` か docs の validation スクリプト。CI の外）

**G8 N = 3, 4 の多体項での合成ゲート（回転 iid 参照）**
- 保証：3 体・4 体インスタンス内の対を含む pair 移動の連鎖全体が正しい分布を出す。
- オラクル：§1.4 の回転 iid（10⁶ サンプル、E は `total_energy` か手書きの積の式）。
- 試作（F3 相当、J = −0.5, K = 0.3, λ = 1, β = 2, θ = π/5）：
  - 参照 ⟨u·T⟩ = 0.2545。
  - CMC = 0.2550。
  - naive な pair ΔE = 0.1908（25 % のずれ）。⟨M_z⟩ も 2.050 → 1.921。
- 役割：naive ΔE は G2 で決定論的に殺せるので、これは合成の確認。
  F3 は**時間反転について奇**なので、M_z' ≤ 0 の棄却漏れ（−n への混入）もここで見える。
  偶のモデル（F(n) = F(−n)）ではこの変異は見えない、という点に注意。
- 時間：参照 2〜5 s ＋ CMC 1 s。高速化できればユニットの「中」枠に入れられる。

**G9 大きい N での線形応答の恒等式（Callen–Callen の厳密版）**
- 保証：FL（sc 4×4×4 の強磁性、βK = 1e−3）で
  K_eff(T)/K = ⟨P₂(e·M̂)⟩_iso(T) を 1 % で確認する。l = 4 の立方なら P₄。
  オラクルの ⟨P_l(e·M̂)⟩ は既存の `run_mc` の等方 run で、ユーザー Observable として測る。
- 潰すもの：
  - |z_j| 因子の誤り。試作（N = 32、全対ペア、T = T_c/2）で τ が 12 % ずれた。示量的な効果。
  - トルクの規格化。
  - ランダムな相手が近傍になる確率（~6/63）経由での naive ΔE（感度は要確認）。
  - 重み付き/重みなしの取り違え（2 副格子フェリにすれば）。
- 見えないもの：M_z² の欠落（試作で 1.3 %。O(1/N) なので有意にしにくい）。
  これは G5/G6 の担当。
- 時間：分単位。手動または夜間。

**G10 Callen–Callen の漸近則（K ∝ m³, m¹⁰, l(l+1)/2）：ゲートにしない**
- 理由：
  (i) 漸近則で、補正 O(T)、O(K/J) の大きさが系ごとに違う。
  (ii) 単イオン異方性が前提で、二イオン異方性では指数が変わる（Asselin の FePt では ~2.1）。
  (iii) 低温で 1 − m と 1 − K/K₀ を数 % の精度で測る必要があり、大きな N と長い run が要る。
  (iv) 大きい N では M_z² の Jacobian に盲目。
- 扱い：G9 の恒等式が有限 T で同じ内容を厳密に検査する。漸近則は docs の物理例
  （log–log の傾きを 3 / 10 と並べた図）として載せるにとどめる。

**G11 トルク積分 vs 拘束しない M̂ のヒストグラム（異なる方法どうしの整合）**
- 恒等式：拘束しない MC での M̂ の立体角あたりの密度は ∝ e^{−βF(n)}（同じ F）。
  一軸なら cosθ のヒストグラムから ΔF(θ₁ → θ₂) = −kT ln[p(θ₂)/p(θ₁)]。
  これを ∫ ⟨u·T⟩ dθ（Simpson、9〜17 点）と比べる。
- 実用性：
  - βΔF ≲ 4 の領域（N = 8〜27、小さい K か T_c 付近）でしか使えない。
  - ordered 相では e^{−βNK} の抑制と M̂ の回転拡散（時間 ~N）のため、ヒストグラムの有効サンプルが
    少ない。
  - 精度は 10⁶ sweep で ΔF に ~0.05 kT。
  - 小さい N では回転 iid 参照（G6/G8）が厳密で安い。
- 価値：既存の `run_mc` だけをオラクルにして、中間的な N（回転 iid の ESS が破綻する領域）の
  相互作用格子をパイプライン全体で検査できる唯一の手段。手動検証として 1 本（N = 27、
  sc + 単イオン、T ≈ 0.8 T_c）を推奨する。
- 潰すもの：G9 と同等。小さい N なら Jacobian も。

**G12 本番モデルの自己整合（手動のスモーク）**
- 偶モデルの閉路 ∫₀^π ⟨u·T⟩ dθ = 0、一軸の τ(0) = τ(π/2) = 0、
  ⟨n·T⟩ = 0（式 (4)、誤差の範囲で）。
- 低温極限：一様な拘束基底状態のとき ⟨u·T⟩ → −dE_rigid/dθ（例：−NK sin 2θ）。
  示量的な規格化と符号の確認。
- 注意：一様状態が拘束基底になるのは |J| ≳ K|cos 2θ| のとき（N = 2 での 2 次展開）。
  そうでなければキャントする。

### 決定論ゲート（Tier A 相当、ユニットスイート）

**G13 resume ≡ 中断なし（ビット単位）**
- `test_checkpoint.jl` の `_poison_pair` パターンで、**測定の途中で中断**し、その位置を assert する。
- checkpoint には次を入れる：n(θ, φ)（または θ グリッドの位置）、チェーン RNG、step、
  アキュムレータ、再射影の状態、M の重み、そして fingerprint への n とモーメントの混入。
- 変異：n を保存し忘れて既定値で再開すると、ビット不一致で捕まる。

**G14 θ 点・温度をまたぐタスク数非依存（ビット単位）**
- pair 移動は**色クラスの中でも可換ではない**：M_z と |z_j| がすべての受理に入る。
  だから U1 型の並行 sweep は**存在しない**。
- 並列化は θ 点や温度ごとの独立チェーンだけにする。シードの派生順を固定し、
  ntasks = 1 と 4 で `==` を確かめる（`test_pt.jl` の決定論ゲートと同じ形）。
- 色クラスで並列化した CMC sweep が提案されたら、正しさの証明なしには却下すべき
  （遅延した M_z を使う連鎖は別のマルコフ連鎖になる）。

**G15 PT との合成（同じ n で温度交換）**
- 交換比 π_{β₁}(x₂)π_{β₂}(x₁)/(π_{β₁}(x₁)π_{β₂}(x₂)) では、β によらない
  M_z²/|z_j| が打ち消すので、既存の `_swap_accepts` をそのまま再利用できる。
- ゲート：
  (i) F2u の PT-CMC を 2 段で回し、各段の ⟨u·T⟩ を G6 の求積と比べる。
  (ii) ntasks に依存しないこと（ビット単位）。
  (iii) 交換は同じ n の間に限ることを assert する（θ をまたぐ交換は配置を回転しない限り不正）。
- 変異：交換比に M_z² 比を入れる → (i) で捕まる。

## 4. 「等方モデル → 平均トルク 0」だけでは不十分な理由

SO(3) 不変な E では、Σ_i e_i × ∇_i E = 0 が**一点ごと**に成り立つ（Noether。
大域回転で E が不変）。だから ⟨T⟩ = 0 は、どんな（間違った）アンサンブルでも成り立つ。
生き残る変異：

- Jacobian 系すべて。
- pair ΔE の誤り。
- θ / φ の規約。
- トルクの符号と軸（0 の符号は反転しない）。
- 重み付きの取り違え。
- 再開時の誤り。

殺せるのは、トルク観測量の計算が等方性を壊す誤り（勾配の一部の項の欠落など）だけ。
したがってこれは G3 の一点ごとの恒等式（|ΣT| < 1e−12）に格下げして、統計ゲートとしては扱わない。
同じ理由で、ゼロ異方性（K = 0）のトルクゲートは Jacobian について何も言わない。
Jacobian を見る統計量は**回転不変な |M| 系の分布**（G5）か、**K ≠ 0 で小さい N のトルク**
（G6/G7）でなければならない。

## 6. 実装者への注意（オラクルが成り立つための前提）

1. **非活性サイト**：E = 0 のサイトはパッケージ上「非活性」で、sweep が飛ばす。
   CMC では、モーメントを持つサイトは拘束を通じて結合するので、凍結すると条件付き分布が
   一様でなくなり偏る。「CMC は m_a ≠ 0 のサイトをすべて動かす」か「M は活性サイトだけで定義」
   のどちらかを決め、G5 の一変種（不活性な自由スピンを含む二量体）で固定する。
2. **overrelaxation と Zeeman**：単一サイトの OR は M を動かすので、拘束と両立しない。
   CMC の run では OR を禁止するか、pair 版を作って G1/G4 を通す。Zeeman 項は単なる body-1 項
   としてトルクに入る（G3 が担保）。
3. **反平行の flip 提案**（既存の 0.2）：対称なので正しいが、補償 e_j⊥ += 2e_i⊥ がほぼ不正になり、
   効率が悪い。正しさには影響しない（G5 で確認できる）。
4. **トルクの規約**を決定記録に固定する：n(θ, φ) の定義、u = (−sinφ, cosφ, 0)、
   τ_θ ≡ ⟨u·T⟩ = −∂F/∂θ、K の抽出式（一軸：τ = −N K_eff sin 2θ + 高次）。
   K(T) のフィット／積分ルーチンは、合成した閉じた式のトルクから係数を復元する純粋に数学的な
   ユニットテストで別に固定する。
5. **再射影はエネルギーを変える**（異方モデルでは丸め誤差程度の大域回転でも ΔE ~ 1e−16·τ）。
   `_renormalize!` と同じく、再射影の後でゼロから再アンカーする。
