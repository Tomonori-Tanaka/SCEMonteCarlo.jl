# 拘束モンテカルロ（CMC）で磁気異方性の温度依存性を求める — 理論とアルゴリズム調査（報告 A）

対象: SCEMonteCarlo.jl への CMC 実装計画。リポジトリには何も書き込んでいない（読んだだけ）。
主な出典: P. Asselin, R. F. L. Evans, J. Barker, R. W. Chantrell, R. Yanes, O. Chubykalo-Fesenko, D. Hinzke, U. Nowak, PRB 82, 054415 (2010)。arXiv:1006.3507v1 の全文（30 頁）を読み、下の頁番号は arXiv 版のものである。
ダウンロードした資料は `../../../../references/papers/ (local-only; originally downloaded as) ` に置いた。数値の小さな検算は `scripts/A/check.py`、`n2.py`、`n2b.py` で行い、いずれも 10 秒以内で終わる。

## 0. 要点（先に結論）

1. **論文の受理則とヤコビアンは正しい。** 拘束付きの測度を自分で導いても、論文の式 (A10)–(A11)（p.7 の step 7 と p.23）と一致した。ただし論文の書き方には表に出ていない選択が一つある。
   - **Mz² 因子は、拘束を立体角上のデルタ δ_{S²}(M̂, n̂) で課すと決めたことに対応する。** その結果、論文の F は「通常のカノニカル集団で M̂ の向きが従う確率密度（立体角あたり）」の −kT ln そのものになる。
   - Mz² を落とすと δ²(M_⊥) の集団になる。こちらもトルク恒等式 (C15) を満たす、別の F をもつ集団である。違いは 1 スピンあたり O(kT/N) で、大きな N では消える。小さな N のテストでは差がはっきり出る。
   - N=3 で検算した（§1.6）。論文の式は独立なオラクルと 1σ 程度で一致し、Mz² を落とした版は大きく外れた。
2. **運動学的な棄却（step 4 の √ の中身が負、step 5 の Mz' ≤ 0）は「その場に留まる手（null move）」として数えなければならない。** 数えずに提案をやり直すと、定常分布が π(x)(1−r(x)) に偏る。N=3 の検算では、トルクが 8σ 以上ずれた。
   - Toga et al. (2016) の手順は棄却時に「(A) に戻る」と書いてあり、どちらとも読める。実装では null move として数える。
3. **トルクと F の関係**（自分で確かめ、ヒストグラムとも数値で一致した）は次のとおり。
   - ⟨T⟩ = −n̂ × ∂F/∂n̂、ここで T = −Σ_i e_i × ∂H/∂e_i。
   - 極座標では ⟨T⟩·ê_φ = −∂F/∂θ、⟨T⟩·ê_θ = (1/sinθ) ∂F/∂φ、⟨T⟩·n̂ = 0（厳密）。
4. **拡張それぞれの判定。**
   - (a) モーメントで重みを付けた M = Σ m_a e_i：補償の式を (m_i/m_j) 倍にするだけで、受理則の形は変わらない（N=3、m=(1, 0.4, 1.5) で検算）。エルゴード性の証明（App. B）は等しいモーメントの場合しか扱っていない。
   - (b) 副格子 / Néel 拘束：使える。重み ±1、または部分集合だけに拘束をかけるハイブリッド方式（VAMPIRE と同じ）。
   - (c) |M| の拘束：研究レベル。CMC の中で |M| のヒストグラムを取るのが王道。
   - (d) 一様な Zeeman 場：そのまま使える。
   - (e) 多体相互作用：ΔE を 2 スピン同時に動かした差にするだけで、ほかは何も変わらない。ただし並列化のやり方は変わる（後述）。
   - (f) ブロック拘束：ブロックごとのヤコビアンとブロックごとのトルク恒等式で、そのまま拡張できる。
5. **推奨。** 主手法は Asselin 型 CMC とする。これを王道として、次の三つを足す。
   - 重み付き M（Toga 型）
   - 部分集合の拘束（ハイブリッド CMC）
   - トルクを球面調和の勾配へ直接、線形最小二乗でフィットする
   - 拘束なし MC で M̂ のヒストグラムを取る方法は、主に小さな N のテスト用オラクルとして使う。

## 1. アルゴリズム（論文どおり）とヤコビアンの独立な導出

### 1.1 論文の手順（Sec. III、p.6–7）

拘束軸は +ẑ に固定する。一般の軸には全体を回転すれば帰着できる、と論文は述べている。

1. 主スピン i と補償スピン j を選ぶ。隣どうしである必要はない。
2. 主スピンを通常の MC と同じように動かす。v を等方な正規分布から取り、S_i + S_i × v を規格化して S_i' とする。この提案密度は S_i と S_i' のなす角だけで決まるので、dΩ について対称である。
3. 補償スピンの xy 成分を S_jx' = S_jx + S_ix − S_ix'（y も同様）とし、M_x = M_y = 0 を保つ。
4. z 成分は S_jz' = sign(S_jz) √(1 − S_jx'² − S_jy'²) とする（**補償スピンの z の符号は保つ**）。√ の中身が負なら null move。
5. Mz' = Mz + ΔS_iz + ΔS_jz を計算する。**Mz' ≤ 0 なら null move。**
6. ΔH を計算する。
7. 受理確率 P = min[1, (Mz'/Mz)² |S_jz| / |S_jz'| · exp(−βΔH)]。
8. 確率 P で受理し、そうでなければ null move。N 回の試行（null を含む）を 1 ステップと数える。

### 1.2 ヤコビアンの独立な導出（余面積・デルタ関数による）

**目標の測度。** 拘束集団を、カノニカル分布を M̂ = n̂ で条件付けたものと定義する。

  π(dξ) ∝ ∏_k dΩ_k · e^{−βH(ξ)} · δ_{S²}(M̂(ξ), n̂)

ここで M = Σ_k m_k e_k とし、論文の場合は m_k = 1 である。δ_{S²} は立体角についてのデルタ関数とする。M ∥ n̂ の近くでは次が成り立つ。

  δ_{S²}(M̂, n̂) = |M|² δ²(M_⊥) Θ(M_∥)

（確認: ∫d³M f · |M|² δ²(M_⊥) Θ = ∫_0^∞ dM_∥ M_∥² f(M_∥ n̂) = ∫ |M|² d|M| f(|M| n̂) ＝ 立体角デルタの定義。）

**ファイバー上の条件付き密度。** i, j 以外を固定し、C = Σ_{k≠i,j} m_k e_k と置く。dΩ_j を枝ごとに dS_jx dS_jy / |S_jz| と書き、δ² を S_j⊥ で積分する。

  δ²(m_i S_i⊥ + m_j S_j⊥ + C_⊥) dS_jx dS_jy = m_j^{−2}

すると、S_i を（dΩ_i に関する）座標としたファイバー上の密度は次のようになる。

  ρ(S_i) ∝ e^{−βH} · M_∥² / (m_j² |S_j∥|),  S_j⊥ = −(m_i S_i⊥ + C_⊥)/m_j,  S_j∥ = σ √(1 − |S_j⊥|²)

ここで σ = ±1 は枝で、M_∥ = M·n̂ > 0 である。

**MH 比。** S_i の提案は dΩ について対称で、S_j は同じ枝 σ の上で決定論的に決まる。逆向きの手（S_i' → S_i、同じ σ）は元の S_j に戻るので、可逆である。m_j は 1 回の手の中で定数なので打ち消し、次の比が残る。

  ρ'/ρ = (M_∥'/M_∥)² · |S_j∥| / |S_j∥'| · e^{−βΔH}

**論文の式 (A11) と完全に一致する。** 論文の App. A（p.22–23）は、(S_i, S_j) から (S_i, M̂) への変数変換の行列式 Mz^{−2} と、射影の因子 1/|S_z| で同じ結果を出している（A7–A10）。この導出も正しい。

### 1.3 棄却条件の正しさ

- **√ の中身が負**：対応する状態が存在しない。無限大エネルギーの架空状態とみなして null move にすれば正しい（論文 p.7 の説明と同じ）。
- **M_∥' ≤ 0**：その状態は M̂ = −n̂ の多様体に属するので、目標分布の外である。null move は正しい。
- **補償スピンの符号を保つこと**：ファイバーは 2 枚のシートが |S_j⊥| = 1 でつながった形をしている。各シートの上で詳細つり合いが成り立てば、目標分布は保たれる。シートをまたぐ遷移は、j が主スピンになったときに起こる。
- **重要：null move を必ず数えること。** 運動学的に失敗した提案を数えずにやり直すと、実効的な遷移核は K'(x→y) = K(x→y)/(1−r(x)) になる（r(x) は x から失敗する確率）。このとき詳細つり合いは π'(x) ∝ π(x)(1−r(x)) について成り立ち、**偏った分布を正しくサンプルしてしまう**。§1.6 の "retry" 行がこの偏りの実測である。
  - Toga et al. (arXiv:1606.00333, Sec. II B の手順 (C)(D)) は失敗時に「return to (A)」と書いている。試行回数を増やす意味なら正しく、そうでなければ偏る。文面からはどちらとも決められない。

### 1.4 詳細つり合い（まとめ）

順序付きのペア (i, j) を、状態によらない確率 q_ij で選ぶ。q_ij = q_ji である必要はない。逆向きの手は同じ役割の (i, j) を使うからである。

各 (i, j) の遷移核は、§1.2 のファイバー条件付き密度について詳細つり合いを満たす。ファイバーは「i, j 以外を固定した」条件付けにすぎないので、これは全体の π について詳細つり合いを満たすことと同じである。状態によらない重みで混合しても、詳細つり合いは保たれる。

これから実装上の自由度が二つ出てくる。
- 主スピンのステップ幅は、ペアの種類（例：Fe→Fe、Pt→Fe）ごとに変えてよい。状態によらなければよい。
- 主スピンの提案は、dΩ について対称なものなら何でもよい。パッケージにある Rodrigues 回転と確率 0.2 の反転の組（updates.jl）も条件を満たす。ただし反転では補償スピンが 2|S_i⊥| を吸収しなければならず、ほぼ必ず運動学的に棄却されるので、CMC では無駄になる。

### 1.5 エルゴード性

App. B（p.23–26）は**モーメントが等しい場合だけ**を証明している。
- Lemma 1：S_z < 0 のスピンを、ほかのスピンに z = 0 面を越えさせずに上半球へ移せる。
- Lemma 2：上半球のスピンのうち一つを z 軸上へ移せる。xy への射影が「重心のまわりの対称移動」になり、レンズ形の許容領域が凸であることを使う。
- 証明はおおむね妥当である。ただし Lemma 1 の最後の 1 手（主スピンが赤道をまたぐ）は「ample supply of paths」という定性的な論証にとどまる。

重みが等しくない場合（§3a）、論文の証明は適用できない。N=2、m_1 > m_2 の例で調べると次のようになる。
- 多様体は「S_1 が上半球の |S_1⊥| ≤ m_2/m_1 のキャップにあり、S_2 は両方の枝をとる」形をしている。
- 2 枚のシートは、j=1 を補償スピン、i=2 を主スピンとする手でつながる。
- 下のキャップは許されない（m_2 < m_1 なので M_∥ > 0 にできない）。

一般の N での証明は自分ではしていない。実務上は、等モーメントのペアと「小さいモーメントを主・大きいモーメントを補償」のペアを両方入れておけば、つながりは十分と考えられる。

## 2. トルク推定量、符号、K(T) の取り出し

### 2.1 恒等式（App. C、p.27–29、式 (C15)）

  ⟨Σ_i e_i × ∂H/∂e_i⟩_{n̂} = n̂ × ∂F/∂n̂,  つまり  ⟨T⟩ = −n̂ × ∂F/∂n̂,  T ≡ −Σ_i e_i × ∂H/∂e_i

**導出の骨子**（自分で確かめた）。
- 全スピンを一斉に回す R は、多様体 n̂ から多様体 Rn̂ への測度を保つ全単射である。∏dΩ と δ_{S²} はどちらも回転で不変だからである。
- したがって Z(Rn̂)/Z(n̂) = ⟨e^{−β[H(Rξ)−H(ξ)]}⟩_{n̂}（C6）が成り立つ。
- 無限小の回転 Rv = v + dθ n̂_rot × v を入れると、H(Rξ) − H(ξ) = dθ n̂_rot · Σ e × ∂H/∂e となる（C8–C9）。
- この恒等式は**有限の N で厳密**であり、熱力学極限は必要ない。
- 動径方向の勾配成分は e × で消えるので、∂H/∂e は H を球面の外へどう拡張しても同じ結果になる。パッケージの `site_gradient`（接平面に射影済み）をそのまま使える。

**副産物：** 回転の重み f(|M|) を何にしても、回転共変な集団なら (C15) は成り立つ。したがって (C15) と「回転ループに沿ったトルクの線積分が 0（curl-free）」は、Mz² 因子の有無を区別できない。区別するには §6 の O4–O6 を使う。

### 2.2 極座標での成分

n̂ = (sinθ cosφ, sinθ sinφ, cosθ) と置く。
- ⟨T⟩·ê_φ = −∂F/∂θ（xz 面、φ=0 なら ê_φ = ŷ なので T_y = −∂F/∂θ。Gong et al. 2019 の式 (8)「F = −∫T_y dθ」と同じ）
- ⟨T⟩·ê_θ = (1/sinθ) ∂F/∂φ
- ⟨T⟩·n̂ = 0（n̂ まわりの回転は多様体を自分自身に写すので、どんな H でも厳密に成り立つ）

一軸の場合、F = K sin²θ なので T_φ = −K sin2θ（復元トルク）となる。論文の Fig. 1 は「Tx」を正の sin2θ の形で描いているが、これは回転面の取り方による。たとえば yz 面（φ=π/2、ê_φ = −x̂）なら T_x = +K sin2θ になる。

### 2.3 F の積分（論文の式 (2)、p.5）

  F(n̂) = F(n̂_0) + ∫ (n̂' × ⟨T'⟩)·dn̂'

確認すると、n̂ × ⟨T⟩ = −n̂ × (n̂ × ∂F) = ∂F_tan（接平面の勾配）なので、被積分関数は dF そのものである。式は正しい。⟨T⟩ は厳密に勾配場なので、積分は経路によらない。「reversibly」という但し書きは、各点で平衡に達しているという意味にすぎない。

### 2.4 K(T) の取り出し方

- **一軸**：F = K1 sin²θ + K2 sin⁴θ + K3 sin⁶θ に対し、−T_φ = sin2θ (K1 + 2K2 sin²θ + 3K3 sin⁴θ)。係数について線形なので、最小二乗でトルクを直接フィットできる。
  - 論文は θ=45° の 1 点（sin2θ の最大）だけで K を求めた。
  - FePt は sin²θ からずれたので、トルクを θ について積分した（Sec. V、Fig. 3）。
- **立方**：論文の式 (1) の −(Kc/2)Σ S_α⁴ は、+Kc(α1²α2² + α2²α3² + α3²α1²) + 定数と同じである。xz 面では F = (Kc/4) sin²2θ、−T_φ = (Kc/2) sin4θ となり、最大は θ = 22.5°（論文 p.9 の選択と一致）。
- **一般の結晶（SCE、高い l）**：F(n̂) = Σ_{l 偶, m} κ_lm(T) Z_lm(n̂) と、点群で不変な組み合わせで展開する。⟨T⟩(n̂) = −Σ κ_lm n̂ × ∇Z_lm(n̂) は κ について線形なので、複数の方向（既約領域を覆う点の集合、極角と方位角の両方）のトルクにまとめて、重み付き最小二乗でフィットする。重みはビニングで求めた分散を使う。
  - Ellis et al. 2017 は、F を積分するより「トルクを直接フィットするほうが角度に敏感で正確」と報告している。
  - 積分は、閉じたループで 0 になるかどうかの整合性チェックとして残す。
- **Callen–Callen 則が当てはまるのは球面調和の係数 κ_l であって、K1 そのものではない。** 例えば F = κ_2 P_2 + κ_4 P_4 なら、K1 = −(3/2)κ_2 − 5κ_4、K2 = (35/8)κ_4 となる。K1 には κ_2 ~ m³ と κ_4 ~ m^10 が混ざるので、K2 ≠ 0 の系では K1 は単純なべき乗則にならない。
- **時間反転**：H が全体として偶数（Σl が偶）で B=0 なら、全スピンを反転する写像が多様体 n̂ を −n̂ へ測度を保って写すので、F(n̂) = F(−n̂)、つまり偶数の l だけが残る。
- **F と U**：論文 p.9–10 は ∂F/∂θ ≈ ∂⟨H⟩/∂θ であり、エントロピーの寄与は小さいと述べている。一般には区別すべきだとも書いている。⟨H⟩(θ) は同じ実行で測れるので、両方出すとよい。

### 2.5 有限の N での F の意味

  F_N(n̂) = −kT ln ∫∏dΩ e^{−βH} δ_{S²}(M̂(ξ), n̂) = −kT ln P_N(n̂) + 定数

ここで P_N はカノニカル集団での M̂ の pdf（立体角あたり）である。これは示量的で、K_eff = ΔF/N（あるいは /V）とする。

非示量的な部分には二つある。
- 測度の取り方による部分：δ²(M_⊥) と比べると −kT ln⟨|M|^{−2}⟩_{n̂} の差がある。
- 縦方向の揺らぎによる部分。

角度に依存する部分は、1 スピンあたり O(kT/N) である。Callen–Callen のプロットで使う m は、拘束集団での ⟨M·n̂⟩/Σm_a とする。これ自体も O(K) だけ θ に依存するので、どの角度での値を使ったかを明記する。

## 3. 必要な拡張と判定

### (a) モーメントで重み付けした M = Σ m_{a(i)} e_i

**判定：補償則を変えればそのまま使える。受理則の形は変わらない（導出は §1.2、検算は §1.6）。**

座標系に依らない形で書くと、次のようになる（n̂ の座標系に回さなくてよい）。

  S_j⊥' = S_j⊥ − (m_i/m_j)(S_i⊥' − S_i⊥)
  S_j∥' = sign(S_j∥) √(1 − |S_j⊥'|²)
  S_j' = S_j⊥' + S_j∥' n̂
  M_∥' = M_∥ + m_i ΔS_i∥ + m_j ΔS_j∥
  P = min[1, (M_∥'/M_∥)² |S_j∥| / |S_j∥'| e^{−βΔE}]

Toga et al. 2016（Nd2Fe14B、Sec. II B、手順 (C)–(E)）と同じ形である。

- **m_i/m_j が大きいペア（例：Fe を主、Pt を補償、比はおよそ 5–10）**：補償スピンの横方向の変位が増幅され、ほとんどが √ の中身が負で棄却される。正しさは保たれるが、無駄が多い。
  - ペアの選び方を、状態によらない形で「小さいモーメントを主・大きいモーメントを補償」と「同じ種類どうし」に偏らせる。
  - あるいはペアの種類ごとにステップ幅を変える。
- **補償スピンが M と反平行（S_j∥ < 0）の場合**：そのまま扱える。符号は保たれ、ヤコビアン |S_j∥|/|S_j∥'| もそのまま使える。
- **フェリ磁性体で正味の M_∥ が小さい場合**（補償点の近く）：(M_∥'/M_∥)² が大きく揺らぎ、M_∥ ≤ 0 による棄却が増える。そもそも正味モーメントの向きが優勢な副格子の向きを代表しなくなる。この場合は (b) の副格子拘束を使う。
- **Nd2Fe14B について**：古典スピン模型の e_i が何を表すかによる。Nd の 4f の全モーメントは Fe と平行で（Gong 2019 の Table I 付近の記述）、軽希土類なので正味の M は大きい。重希土類（Dy、Tb）の系ではこの点が深刻になる。
- **どちらの拘束が「物理的」か**：トルク測定が見ているのは全モーメントの向きである。副格子間の傾きが小さければ F_total(n̂) と F_Fe(n̂) は先頭の次数で一致するが、一般には別の関数になる。既定は Toga と同じく全モーメントで重み付けしたものにし、選択肢として (b) を用意するのを勧める。

### (b) Néel ベクトルや副格子の拘束（メモ）

**判定：そのまま使える（重み付きの特殊な場合）。** 二つのやり方がある。

- **部分集合 G だけを拘束する**：M_G = Σ_{k∈G} m_k e_k を固定し、ペアは G の中から選ぶ。G に入らないスピンはパッケージ既存の 1 スピン Metropolis や過緩和で自由に動かす。これは VAMPIRE の hybrid-constrained-monte-carlo と同じ考え方である（Ellis et al. 2017 で使われている）。
  - トルクには全スピンの和をとる。G に入らない自由なスピン k については、S² 上の部分積分により ⟨e_k × ∂H/∂e_k⟩ = 0 となる（回転の生成子は発散がなく、拘束因子は e_k に依らない）。したがって、平均としては G のスピンだけの和でも同じ値になる。
- **Néel ベクトル**：符号付きの重み σ_k = ±1 で L = Σσ_k e_k を拘束する。ヤコビアンは同じ形で、M_∥ を L_∥ に置き換える。全体回転の論法がそのまま使えるので (C15) も成り立つ。

### (c) |M| の拘束（縦方向の自由エネルギー、メモ）

**判定：研究レベル、あるいは別の方法を使う。** CMC は向きだけを固定し、|M| は自由である。ただし CMC が |M| の分布を自然に与える点は使える。

  縦の Landau 自由エネルギー（d³M あたり）: Φ(|M| n̂) = −kT ln[p(|M| | n̂) / |M|²]

p は CMC で測った |M| の周辺密度（d|M| あたり）である。裾はアンブレラサンプリングで補う。これが王道の道筋である。

ベクトル M をまるごと固定するには、ペアを m_iS_i + m_jS_j を軸に同じ角だけ回す手がある（§4 で導出、ヤコビアンなし）。ただし |M| についての一般化力の恒等式（∂F/∂|M| を平均として書く式）は、全体回転のような対称性がないので簡単には作れない。

### (d) 一様な Zeeman 場との共存

**判定：そのまま使える。**
- ΔE に Zeeman の項（パッケージでは −μ_B m_s e·B）を入れるだけでよい。
- トルクには Zeeman 分 T_Z = Σ μ_i e_i × B = M_μ × B が加わる。拘束の重みが μ と同じなら M_μ = M_∥ n̂ なので、⟨T_Z⟩ = ⟨M_∥⟩ n̂ × B となる。
- B ∥ n̂ のとき：Zeeman のトルクは 0 で、場は |M| とだけ結合する。Tc の近くで縦の揺らぎを抑える効果があるが、K(T, B) という場依存の量を見ることになる。これは偏りではなく物理である。
- 重みが同じなら、H_Z = −M_∥(n̂·B) を追跡している M_∥ から O(1) で計算できる。
- 簡単なオラクル：等方的な H に Zeeman を足しただけの系では、配置ごとに T = M_∥ n̂ × B が厳密に成り立つ。

### (e) 多体相互作用（2 スピンが同じクラスターに入る場合）

**判定：ΔE を 2 スピン同時の差にするだけで、ほかは何も変わらない（確認済み）。**

ヤコビアンと拘束は純粋に幾何的で、H に依らない（§1.2 の導出には H が e^{−βH} としてしか入らない）。したがって、必要なのは次だけである。

  ΔE = [H(S_i', S_j) − H(S)] + [H(S_i', S_j') − H(S_i', S_j)]

i を動かしてから、更新済みの i を使って j を動かす。パッケージの言葉で言えば、j の site_coeffs を i を更新したあとに再計算する。

実装上の注意点は次のとおり。
- i ≠ j とする。
- 同じサイトが 1 つのクラスターに 2 回現れる場合（小さなセルでの周期像、ユーザーのメモにある self-pair の件）でも、クラスターの積を丸ごと再計算すれば正しい。
- **並列化のやり方は変わる。** 受理則が全体の M_∥ を通じて全ペアを結びつけるので、色クラスごとに独立に回す今の並列スイープは使えない。直列で回すのが安全である。(f) のブロック拘束なら、ブロックごとの M_b がクラスターを共有しない限り独立になる。

### (f) ブロック / セル拘束（拘束グループが多数）

**判定：そのまま拡張できる。**
- 互いに重ならないブロック B_b のそれぞれに、方向 n̂_b を課す。ペアは同じブロックの中から選び、ブロックの M_{b∥} でヤコビアン (M_{b∥}'/M_{b∥})² |S_j∥|/|S_j∥'| を計算する。
- 各ブロックには 2 スピン以上が必要である。等モーメントなら App. B をブロックごとに適用できる。
- **ブロックごとのトルク恒等式**：⟨T_b⟩ ≡ ⟨−Σ_{i∈b} e_i × ∂H/∂e_i⟩ = −n̂_b × ∂F/∂n̂_b。ブロック b のスピンだけを回す写像も、多様体どうしの測度を保つ全単射だからである。
  - ブロック間の交換は、ブロックだけの回転では不変でないので、T_b に入る。
  - これにより、粗視化した F({n̂_b}) からねじれ配置（n̂_b のらせん、波数 q）の F ≈ A q² V を作り、A(T) を出せる。
- **注意**：拘束がブロック境界で「固い」壁を作るので、F({n̂_b}) はブロックの大きさに依存する。ブロックサイズで外挿する必要がある。
- **先例**：VAMPIRE の grain ごとの拘束（Ellis et al. 2017、各 grain のトルクを計算）。Atxitia et al. PRB 82, 134440 (2010) は A(T) を磁壁と spin wave の二つの方法で出しているが、CMC を使ったかどうかは確認していない。

## 4. 落とし穴と効率

- **null move を数えること**（§1.3）。最も重要で、偏りを実測した。
- **拘束軸と座標系**：H は結晶の座標系で計算したまま、補償だけを n̂ に平行・垂直に分けた座標系に依らない式で行う（§3a）。Hamiltonian を回転させる（Wigner-D）必要はない。
  - M は増分で追跡し、定期的に一から計算し直す。M_⊥ のずれ（丸め誤差）を監視する。ずれは小さいが、上限を assert しておく。
- **θ ≈ 90° での受理率**：アルゴリズムは常に n̂ の座標系で動くので、軸の向きによって受理率が特別に悪くなることはない。
  - 物理としては、磁化容易軸と困難軸では対称性からトルクが 0 になる。困難軸の近くでは |M| が小さくなり F が平らになる（論文 Sec. V の FePt、p.10–11）。
  - 受理率を下げるのは、√ の中身が負になる棄却（補償スピンが赤道の近くにある、高温）と、M_∥ ≤ 0（Tc の近く）である。
- **ステップ幅の調整**：調整は平衡化のあいだだけ行い、測定中はステップ幅を固定する（パッケージの `_adapt_step!` の流儀）。ペアの種類ごとに変えてよい。
- **有限サイズ効果**：K/N には O(1/N) の補正がある。測度の取り方による部分と縦の揺らぎによる部分である。2 サイズ以上で外挿するか、差を確認する。
  - Tc より上では、N → ∞ で拘束 F の角度依存は消える。有限の N では、1 スピンあたり O(1/N) の残りがある。
- **自己相関**：拘束は全体回転（Goldstone モード）を取り除くので、方向が拡散することはない。これが CMC を使う理由である。
  - 残る遅いモードは、長波長の spin wave（局所 Metropolis では緩和時間がおよそ L² スイープ）と、Tc の近くでの |M| の緩和である。
  - 補償スピンを遠くから選ぶと、横方向のモーメントを非局所的に移すことになり、長波長モードの緩和を助ける可能性がある。
  - トルクの積分自己相関時間をビニングで測る（パッケージに binning.jl がある）。論文の規模は 16000 スピンで平均 5 万ステップ、FePt は平衡化 1 万 + 平均 7 万ステップ。
- **局所ポテンシャルが強く多峰的な場合**（Nd の高次 l、easy cone）：CMC では 1 スピンを自由に反転できないので遅い。Nd を G から外し（ハイブリッド）、既存の反転提案や過緩和で動かすのが有効である。
- **1 スピン Metropolis や過緩和を混ぜられるか**：拘束したスピンに混ぜるのは**不可**である（M̂ が変わる）。拘束しないスピンになら可（ハイブリッド）。
  - 「1 スピンを動かしてから全体を回して M̂ を戻す」手（回転参照系）は、ヤコビアンがつき、毎回 O(N) の全エネルギーが必要になるので勧めない。
  - **M を保つペア回転**は混ぜてよい。導出：m_iS_i + m_jS_j = P を固定したファイバーは、P̂ まわりの回転の軌道（円）である。同じ回転を 2 スピンに作用させると ∏dΩ も M も保たれるので、その円上の条件付き参照測度は一様になる。したがって、角度 φ を対称な分布から選べば、受理は純粋に e^{−βΔE} でよい。|M| を変えないので、CMC の手と組み合わせて使う。
- **Replica exchange（並列テンパリング）**：同じ n̂ のレプリカどうしなら、交換則は通常のとおり min[1, e^{(β_r−β_s)(E_r−E_s)}] でよい。拘束多様体とその測度（Mz² 因子を含む）は温度に依らない参照測度だからである。
  - 異なる n̂ のレプリカ間でも、全体回転で写して H(Rξ) を評価すれば交換できる（ハミルトニアン RE）。ただし 1 回あたり O(N) かかり、必要になってから考えればよい。
- **トルクの計算コスト**：1 回の測定で O(N × クラスター数) かかる。`energy_gradient!` がそのまま使える。
  - 等方的な項（全 L = 0 に結合したもの）は配置ごとに厳密に 0 になるので、分離できれば省ける。分離が厳密でなければ全体を計算する。
- **角度ごとのウォームスタート**：前の角度で平衡化した配置を全体回転して次の n̂ に持っていく。回した配置は新しい多様体上の正当な状態なので、平衡化が短くて済む。

## 5. 代替手法と推奨

1. **Lagrange 乗数（拘束場）**：横方向の場 B_c を自己無撞着に調整し、⟨M̂⟩ = n̂ を満たすようにする。つり合いの式 ⟨T_aniso⟩ + ⟨M⟩ × B_c = 0 から異方性トルクがわかる。
   - 利点：普通の MC（クラスター更新や PT）がそのまま使える。
   - 欠点：反復が必要で、有限の N では向きが揺らぐ。困難軸の近くでは強い場が要り、場が誘起する磁化で集団が変わる（とくに Tc の近く）。Legendre 変換も必要になる。Curie–Weiss 極限では §6 O8 の h_⊥ と同じものになる。
2. **拘束なし MC で M̂ のヒストグラムを取る、あるいは重み付け**：論文の F そのもの（§2.5）が得られる。F の障壁 K_eff N が数 kT 程度の小さな N でしか使えない。大きな N では、M̂ についてのアンブレラや Wang–Landau と WHAM が必要で、扱いが重い。**小さな N のオラクルとしては最良**である。
3. **回転参照系 / O(K) の摂動**：等方的な系の拘束なし MC で、各配置を瞬間の M̂ を n̂ に合わせるように回して ⟨V⟩ を取る。O(K) で厳密（§6 O7）だが、高次では厳密でない。弱い異方性の場合と、線形次数での on-site と二イオンの分解に向く。
4. **内部エネルギーの経路** ⟨H⟩(θ)（Mryasov et al. 2005 の流儀）：F との差は TS の角度依存で、多くの場合は小さい。CMC の副産物として測れる。
5. **拘束付きの spin dynamics / LLB**：対象外とする。

**推奨（「王道」）**：主手法は Asselin 型 CMC とする。この方法は PRB 2010 で発表され、VAMPIRE に実装され、Toga 2016（Nd2Fe14B）、Gong 2019（Nd2Fe14B）、Ellis 2017（grain）で使われている。具体的には次を実装する。
- 重み付き M（Toga 型）
- 部分集合の拘束（ハイブリッド、VAMPIRE 型）
- ブロック拘束（Ellis 型）
- トルクの直接フィット（κ_lm の線形最小二乗）と、F の積分による整合性チェック
- ⟨H⟩(θ) の併記

2 のヒストグラム法は、テスト用のオラクルとして（パッケージ既存の拘束なし MC を使って）実装する。

## 6. 独立なテスト用オラクル（具体的な式）

**配置ごとの決定論的オラクル（マシン精度）**
- **O1**：任意の H について、T(ξ) = −Σ e × ∂H/∂e = −d/dα H(R_{n̂_rot}(α) ξ)|_{α=0} · n̂_rot が成り立つ（各成分について）。右辺は `total_energy` の有限差分だけで計算でき、勾配のコードとは独立である。
- **O1'**：等方的な H（Heisenberg なら e_i·e_j = (4π/3) Σ_m Z_1m(e_i) Z_1m(e_j)、双二次、全 L=0 結合）では T ≡ 0 になる。
- **O1''**：等方的な H に Zeeman を足した系では T = M_μ × B。
- **O2**：手を 1 回打つごとに、M_⊥ が丸め誤差の範囲で 0、M_∥ > 0、|e| = 1 が保たれる（不変条件のゲート）。

**統計的オラクル**（許容幅は測った σ に余裕を持たせて決める）
- **O3**：任意の H と n̂ で ⟨T·n̂⟩ = 0（§2.2）。拘束座標系の取り違えなどを検出できる。Mz² 因子の有無は区別できない。
- **O4（N=2 の厳密な求積）**：H(e_1, e_2) は任意でよい（2 スピン間の相互作用、異方性、Zeeman を含む）。
  - 等モーメント：多様体は {e_1·n̂ > 0, e_2 = R_π^{n̂} e_1 = 2(e_1·n̂)n̂ − e_1} で（もう一方の枝は M_∥ = 0 になるので除かれる）、
    Z_2(n̂) = 4 ∫_{e·n̂>0} dΩ (e·n̂) exp[−βH(e, 2(e·n̂)n̂ − e)]
  - 重み付き：
    Z_2(n̂) = ∫dΩ_1 Σ_{σ=±} M_∥² / (m_2² |e_2∥^σ|) e^{−βH} Θ(M_∥^σ) Θ(1 − |e_2⊥|²)、ここで e_2⊥ = −(m_1/m_2) e_1⊥。
    **小さいモーメントのスピンを積分変数にとること。** 大きいほうを積分変数にすると、端点の 1/√ 特異点のせいで、中点則の値が格子を細かくしても収束しない（実測：600 点で 1.556、1200 点で 1.744。役割を入れ替えると 1.6839 で安定し、ヒストグラムの 1.665(24) と一致）。この現象は §3a の MC 受理率の問題と同じ構造である。
  - F = −kT ln Z_2、トルクは −∂F/∂θ（数値微分、または被積分関数の微分）で求める。
  - 検算：等モーメントの uniaxial（K=2、β=1、θ=0.7）で、求積から dF/dθ = 1.4462、ヒストグラムから 1.453(27)。
- **O5（相互作用なし、任意の N、任意の 1 イオンポテンシャル、任意の重み）**：iid の棄却サンプリングで M̂ を円錐で条件付ける（§1.6）。CMC のコードとは完全に独立で、Mz² 因子を区別できる（表を参照）。円錐の角 ε による偏りは O(ε²) なので、ε を 2 通り試す。
- **O6（小さな相互作用系、N=3–8 の極小セル）**：パッケージ既存の拘束なし Metropolis で M̂ のヒストグラムを取り、F(θ) = −kT ln[counts/(sinθ Δθ)] を作る。CMC のトルクの積分と比べる（条件：ΔF ≲ 数 kT）。
- **O7（O(K) の厳密な恒等式、任意の N、任意の等方的な H_0）**：H = H_0 + λV とする。拘束集団は n̂ まわりに軸対称なので、加法定理から
    F(n̂) = F_0 + λ Σ_{i,l,m} κ^{(i)}_lm Z_lm(n̂) ⟨P_l(e_i·M̂)⟩_0 + O(λ²)
  となる（1 イオン項の場合）。⟨P_l(e_i·M̂)⟩_0 は、**等方的な H_0 で拘束なし MC を回し、瞬間の M̂ を使って測ってよい**。H_0 が等方的なら M̂ で条件付けた分布は向きによらないので、条件付きの平均と全体の平均が一致する（有限の N でも厳密）。
  - 二イオン項 V = Σ K_ij (c·e_i)(c·e_j) では、F^{(1)} = Σ K_ij B_ij (cos²θ − 1/3) + 定数、B_ij = ⟨(3/2)(e_i·M̂)(e_j·M̂) − (1/2) e_i·e_j⟩_0。
  - 一般の V では、F^{(1)}(n̂) = ⟨∫dψ/2π V(R_{n̂}(ψ) R_{n̂←M̂(ξ)} ξ)⟩_0（M̂ を n̂ に回し、n̂ まわりの方位角で平均する）。
  - テスト：λ を小さくした CMC の ⟨T⟩/λ を −n̂ × ∇F^{(1)} と比べる（λ を 2 通り試して O(λ) を外挿）。
- **O8（Curie–Weiss 型の無限長距離模型の大 N 極限）**：H = −(J/2N)|Σe|² − Σ_i v(e_i)、z(h) = ∫dΩ exp[−βv(e) + βh·e] とする。
  - 拘束付きの鞍点は、h = J r n̂ + h_⊥（h_⊥ ⊥ n̂）として ⟨e⟩_h = r n̂ を満たすように（r と h_⊥ の 3 未知数を）解く。
  - 1 スピンあたりの自由エネルギーは f(n̂) = J r²/2 − kT ln z(h)、1 スピンあたりのトルクは τ = −r n̂ × h_⊥（拘束場とのつり合い）。
  - O(K) では、v = Σκ_lm Z_lm に対して f_aniso = Σ κ_lm Î_{l+1/2}(x) Z_lm(n̂)、Î_{l+1/2} = I_{l+1/2}/I_{1/2}、m = L(x) = coth x − 1/x、x = βJm となる。これが古典的な Callen–Callen の公式で、低温では m^{l(l+1)/2}（l=2 で m³、l=4 で m^10、l=6 で m^21）。二イオンでは平均場で m²。
  - 有限の N では O(1/N) の補正がある。SCE の周期セルで無限長距離模型を表せるかは確認していないので、そのまま使えるかは要確認。
- **O9（低温の厳密な第 1 次）**：κ^{(i)}_l(T)/κ^{(i)}_l(0) = 1 − (l(l+1)/2)(1 − m_i) + O(T²)。m_i = ⟨e_i·n̂⟩ は**サイトごとの値**を使う（P_l(cosθ) ≈ 1 − (l(l+1)/2)(1 − cosθ) から）。
  - 二イオンでは 1 − ½(⟨θ_i²⟩ + ⟨θ_j²⟩) − ½⟨θ_i·θ_j⟩ となり、横方向の相関 ⟨θ_i·θ_j⟩ で指数が 2 からずれる。**1 イオン項の指数 l(l+1)/2 は普遍的だが、二イオン項の指数は相関に依存して普遍的でない**。これはユーザーの研究課題（on-site と二イオンの分離）に直接関係する。
  - 補足：トルクは H について線形なので、⟨T⟩ = Σ_c ⟨T_c⟩ と項ごとに足し算で厳密に分けられる。ただし個々の ⟨T_c⟩ は高次では勾配場とは限らない（∇⟨H_c⟩ との差は −β Cov(H_c, ·) の項）。部分トルクの curl は、項どうしの結合を測る指標になる。分け方として一意なのは O(K) の極限（O7）だけである。
- **O10（Callen–Callen 低温則）**：最近接の強磁性体に弱い 1 イオン異方性を入れ、m が 0.9–0.98 の範囲で d ln κ_l / d ln m が l(l+1)/2 になるか確かめる。漸近則なので許容幅は広めにとり、厳密なオラクルではなく検証のためのゲートとして扱う。
- **O11（対称性）**：F(n̂) = F(−n̂)（偶数の H、B=0）。結晶点群 g について ⟨T⟩(gn̂) = g⟨T⟩(n̂)（固有回転の場合）。
- **O12（T→0）**：基底状態が一様なら、F → E_uniform(n̂)、⟨T⟩ → −n̂ × ∇E_uniform(n̂)（解析的）。

## 7. 論文への注記・正誤

検索の範囲では、正誤表やコメント論文は見つからなかった。気づいた点は次のとおり。

1. **Mz² 因子の意味が書かれていない**（App. A）。δ_{S²}(M̂) という選択と、そこから「F ＝ M̂ の pdf の −kT ln」になることは明示されていない。誤りではない。
2. App. A の「reversible in (S_i, M̂)」が成り立つには、補償スピンの符号を保つこと（step 4）と、主スピンの提案が dΩ について対称であることが暗に必要である。どちらも満たされている。
3. App. B は等モーメントの場合しか証明していない。Lemma 1 の最後の 1 手は定性的な論証にとどまる。
4. 式 (C9)–(C15) の行列表記は、(C10) では ⟨⟩ 付きになっている（PDF の画像で確認した）。(C15) も平均の意味で読む。
5. Fig. 3 の横軸ラベル「Angle from Easy Axis [K]」は単位の誤植で、ラジアンが正しい。
6. Fig. 1 の「Tx」の符号は回転面の取り方による（§2.2）。本文に回転面の記述はない。
7. 式 (1) の交換項は Σ_{i≠j} で 1/2 がなく、二重に数える流儀である。立方項は −(Kc/2)ΣS⁴ ＝ Kc Σα²α² + 定数。
8. Toga 2016 の手順（arXiv 版 Sec. II B）には二点ある。「return to (A)」が null move を数えるのかどうか曖昧なこと（§1.3）。「If M′ < 0」は M_z' ≤ 0 の意味に読むべきこと。
